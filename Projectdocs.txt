If you’re using AI UI generation like Google Stitch, the best approach is to define:

1. **Every page/screen**
2. **Exact components on each page**
3. **Layout structure**
4. **Animation expectations**
5. **Responsive behavior**
6. **Design style**

That gives Stitch much better outputs.

---

# Design System To Tell Google Stitch

You should explicitly mention:

---

## Design Style

```txt id="eq7lvc"
Modern AI SaaS dashboard with futuristic glassmorphism UI, soft gradients, dark mode, floating cards, smooth shadows, rounded corners, and responsive layouts.
```

---

## Animations

```txt id="pfy4ll"
Use Framer Motion animations including fade-ins, stagger reveals, hover scaling, smooth page transitions, floating effects, animated counters, and sliding sidebars.
```

---

## Color Palette

```txt id="vvjzhv"
Primary: #4F46E5
Secondary: #7C3AED
Accent: #06B6D4
Background: #0F172A
Card Background: rgba(255,255,255,0.08)
```
